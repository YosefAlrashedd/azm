# عزم · Azm

تطبيق آيفون لتسجيل التمارين ومتابعة التضخيم أو التنشيف، مبني بـ Expo و React Native. يدعم العربي والإنجليزي.

An iPhone workout tracker built with Expo and React Native, in Arabic and English.

## المميزات

- **تسجيل التمارين:** الخانة الفاضية تنحفظ نفس المرة الماضية، تايمر لكل تمرين ووقت للجلسة كاملة، وعلامة لما تكسر رقمك.
- **جداول جاهزة:** 3 أو 4 أو 5 أيام بالأسبوع، وتقدر تعدّل التمارين.
- **شرح التمارين:** رسم متحرك لكل تمرين يوضح الحركة والعضلة الشغالة، مع طريقة الأداء والأخطاء الشائعة.
- **الوزن والهدف:** السعرات والماكروز حسب هدفك، منحنى للوزن، وتنبيه إذا خبطت أو زدت بسرعة.
- **الخطوات:** عدّاد بهدف يومي وتنبيه لما توصله.
- **الأسبوع:** جدول للكارديو والساونا والجاكوزي حول أيام التمرين.
- **التنبيهات:** تذكير بقياس الوزن كل جمعة، وتذكير تحفيزي أيام التمرين.

## التشغيل

يحتاج [Node.js](https://nodejs.org) وتطبيق **Expo Go** على الآيفون.

```
npm install
npx expo start
```

امسح الـ QR بكاميرا الآيفون. على ويندوز تقدر بدالها تضغط دبل كليك على `start-azm.bat`.

أول ما يفتح التطبيق يسألك عن بياناتك وهدفك وكم يوم تتمرن، ويجهّز لك الخطة.

## النشر على Expo (يفتح بدون كمبيوتر)

1. سوّ مشروع على حساب Expo حقك: `npx eas-cli login` ثم `npx eas-cli init`.
2. حط رابط المشروع في ملف `eas.local.json` (ما ينرفع على GitHub):
   ```json
   { "owner": "your-expo-username", "projectId": "your-eas-project-id" }
   ```
3. انشر: `npx eas-cli update --channel main --platform ios --environment production --message "update"`، أو دبل كليك على `publish-azm.bat`.

بعدها يفتح التطبيق في Expo Go من رابط المشروع، والتعديلات توصل الجوال تلقائياً مع كل نشر.

إصدار Expo Go في الـ App Store يدعم آخر إصدار من Expo SDK بس. لما يطلع إصدار جديد، رقّ المشروع (`npx expo install expo@latest --fix`) وانشر من جديد.

## بنية المشروع

- `App.tsx` — التبويبات، وشاشة الإعداد أول مرة
- `src/screens/` — الشاشات: التمرين، التمارين، الخطوات، الوزن، الخطة، الإعداد
- `src/anim/` — رسم الشخص وحركة كل تمرين
- `src/data/exercises.ts` — التمارين وطريقة الأداء والأخطاء
- `src/logic/` — السعرات وتنبيهات الوزن، الجداول، التنبيهات، الخطوات
- `src/store.tsx` — البيانات، محفوظة على الجهاز (AsyncStorage)
- `src/i18n.ts` — النصوص بالعربي والإنجليزي

فحص الكود: `npx tsc --noEmit`
